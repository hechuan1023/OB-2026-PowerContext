## 实现记录

### 1. 环境与组件验证

- 使用 Qoder 检查 Docker、Python、uv 和本机端口。
- 复用已有 `seekdb-competition` 容器，通过 pyseekdb Server 模式连接。
- 安装 PowerContext 1.4.0，验证 default scope、显式记忆写入、搜索、列表和遗忘。
- 确认 Windows 不使用嵌入式 seekdb，中文向量在应用本机生成。

### 2. 文献链路

- 编写 Markdown/TXT/PDF 解析、front matter、章节或页码出处和重叠分块。
- 在 seekdb collection 中保存分块、向量和结构化元数据。
- 接入向量查询、全文查询和 RRF 混合检索。
- 增加年份、类型过滤和文档删除；示例按来源幂等重导入。

### 3. PowerContext 联动

- 用 `research_constraints` 保存研究设定。
- 用 `research_note` 保存可召回的研究笔记。
- 用 `session_progress` 保存最近查询、过滤条件和前三篇命中标题。
- 检索前读取设定与相关笔记，检索后写回进展；界面显示实际命中的记忆。

### 4. 界面与验收

- 使用 Qoder 生成并迭代中文响应式界面：检索、文献库、研究记忆三个标签页。
- 编写 7 篇原创中文示例和端到端验证脚本。
- 在浏览器中检查实际检索、示例导入、记忆展示与跨会话恢复。
- 保存三张真实运行截图到 `docs/screenshots/`。

## 验证驱动的主要修正

这些修正来自实际运行报错或结果检查，而非仅做静态设计：

1. **中文向量维度不正确**：将 fastembed 参数改为显式 `model_name`，确认 `bge-small-zh-v1.5` 输出 512 维。
2. **混合检索分数误标为相似度**：向量模式将余弦距离转换为相似度；全文和混合模式保留原始检索分数并分开标注。
3. **长查询无法召回研究笔记**：针对未配置向量服务的 PowerContext 文本匹配，用 jieba 抽取关键词，多次搜索后按 artifact 合并。
4. **重复笔记和重复示例**：相同笔记去重，示例导入前按来源清理旧分块。
5. **Markdown 标题混入正文**：段首标题只作为出处，不进入检索文本。
6. **浏览器并发请求导致连接包交错**：对共享 pyseekdb 客户端的数据库操作加锁；以 24 个并发请求复验健康、文献和记忆接口。
