01 / 核心分工

不是把两个名字写进说明，
而是让它们进入同一次检索。

文献证据与长期记忆分开保存，各自做擅长的事。你能在结果页看到哪条记忆真正参与了本次检索。

S文献证据层

seekdb

保存文献分块、中文向量、全文索引和结构化元数据。

  • 向量相似度检索
  • 中文全文检索
  • RRF 混合排序
  • 年份与类型过滤
输入：Markdown · TXT · PDF
研究问题
带出处的结果
P研究上下文层

PowerContext

保存研究设定、研究笔记与最近进展，跨会话继续工作。

  • 研究方向与年份约束
  • 排除词与默认条数
  • 相关研究笔记召回
  • 最近检索进展写回
输出：可解释的记忆应用记录
设计边界

文献正文进入 seekdb；长期研究上下文进入 PowerContext。展示页不伪造在线检索，完整应用在你的本机运行。

04 / 本地复现

把研究环境留在你的机器上。

需要 Python 3.11+、uv 和 Docker。首次下载中文向量模型需联网，之后使用本地缓存；无需外部 LLM 或 Embedding API。

  1. 1

    获取代码

    比赛资产位于仓库的 qoder/litmemo。

    git clone -b 2026-competition-ecosystem https://github.com/hechuan1023/wurenji-ai-project.git
  2. 2

    启动 seekdb

    在项目目录启动本机数据库容器。

    docker compose up -d
  3. 3

    启动 PowerContext

    使用随项目提供的本机配置，无需模型凭据。

    powercontext server run --env-file deploy/powercontext.env.example
  4. 4

    启动 LitMemo

    另开终端，安装锁定依赖并运行应用。

    uv sync --frozen
    uv run uvicorn app.main:app --host 127.0.0.1 --port 8080
阅读完整运行说明 ↗ 查看 Qoder 开发记录

启动后打开 http://127.0.0.1:8080，在“文献库”一键导入示例，再运行验证脚本。
